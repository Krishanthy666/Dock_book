# Security Policy

## Supported Versions

This repository contains the current academic version of the eDocBook Intelligent Healthcare Platform.

| Version | Supported |
| ------- | --------- |
| Current | Yes       |
| Older versions | No |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do not publish the vulnerability publicly.

Please contact the repository owner through GitHub and provide:

- A description of the vulnerability
- The affected component or file
- Steps to reproduce the issue
- Any recommended fix, if available

Security reports will be reviewed as soon as possible.

## Responsible Disclosure

Please allow sufficient time for the issue to be investigated and corrected before publicly disclosing any security-related information.

## Academic Project Notice

This project was developed for academic and portfolio purposes. It is not intended for production healthcare use without further security testing, clinical validation, privacy review, and regulatory assessment.
